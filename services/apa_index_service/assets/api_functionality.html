FastAPI Application for Satellite Data Analysis

This API provides endpoints for retrieving and analyzing satellite data, specifically for identifying areas of interest based on plant intensity in satellite images.

Authentication and Credentials

All data endpoints require valid Sentinel Hub credentials. You must provide the following fields:

  • instance_id - Your Sentinel Hub service instance ID.
  • client_id - OAuth client ID from Sentinel Hub dashboard.
  • client_secret - OAuth client secret corresponding to the client ID.

You can pass these credentials in each request body (recommended based on the current API), or call the helper endpoint below.

/api/set_credentials

Initializes Sentinel Hub configuration with your credentials. You can call this endpoint either via POST (JSON body) or via a GET URL with query parameters.

POST

Request Body: 
{
  "instance_id": "your-instance-id",
  "client_id": "your-client-id",
  "client_secret": "your-client-secret"
}
Returns: JSON confirming initialization.

GET (via URL)

Example URL (replace placeholders with your values):

/api/set_credentials?instance_id=YOUR_INSTANCE_ID&client_id=YOUR_CLIENT_ID&client_secret=YOUR_CLIENT_SECRET

You can paste this directly in the browser address bar or use with tools like curl:

curl "http://localhost:8000/api/set_credentials?instance_id=YOUR_INSTANCE_ID&client_id=YOUR_CLIENT_ID&client_secret=YOUR_CLIENT_SECRET"

Available Endpoints

  • GET /
    Description: Root endpoint that provides this documentation
    Parameters: None
    Returns: Documentation about all available API endpoints
  • POST /api/get_apa
    Description: Retrieves satellite data for a specified time period or day using JSON body
    Required credentials in body: instance_id, client_id, client_secret
    Request Body: JSON with either:
    • Date range format: 
      {
  "start": "2025-01-01",
  "stop": "2025-01-31",
  "resolution_in_m": 10,
  "max_cloud_coverage": 0.5,
  "lake_query": "Maschsee, Hannover, Germany",
  "copernicus_data_service": "ALL-BANDS-TRUE-COLOR",
  "instance_id": "your-instance-id",
  "client_id": "your-client-id",
  "client_secret": "your-client-secret",
  "geojson_file": false,
  "full_apa": false
}
    • Single day format: 
      {
  "day": "2025-01-08",
  "resolution_in_m": 10,
  "max_cloud_coverage": 0.5,
  "lake_query": "Maschsee, Hannover, Germany",
  "copernicus_data_service": "ALL-BANDS-TRUE-COLOR",
  "instance_id": "your-instance-id",
  "client_id": "your-client-id",
  "client_secret": "your-client-secret",
  "geojson_file": false,
  "full_apa": false
}
    Returns: Dictionary with dates as keys and JSON-encoded satellite data as values
  • POST /api/get_available_dates
    Description: Checks for available dates with satellite images for a specified time frame
    Required credentials in body: instance_id, client_id, client_secret
    Request Body: JSON with start and end dates: 
    {
  "start": "2025-01-01",
  "end": "2025-01-31",
  "resolution_in_m": 10,
  "lake_query": "Maschsee, Hannover, Germany",
  "copernicus_data_service": "ALL-BANDS-TRUE-COLOR",
  "instance_id": "your-instance-id",
  "client_id": "your-client-id",
  "client_secret": "your-client-secret"
}
    Returns: Dictionary with available dates and their time slots
