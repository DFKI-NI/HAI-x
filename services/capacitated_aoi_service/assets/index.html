Density Based Clustering API

This FastAPI service provides endpoints to estimate harvestable volume from bathymetry and APA data and to cluster areas of interest by capacity.

POST /volume

Computes a volume estimate GeoJSON. If a matching output file already exists in the working directory, it is returned from cache.

Request body (JSON):

{
  "bathymetry_service_url": "http://localhost:10005/geojson",
  "apa_credentials_service_url": "http://localhost:10003/api/set_credentials",
  "apa_service_url": "http://localhost:10003/api/get_apa",
  "instance_id": "...", "client_id": "...", "client_secret": "...",
  "day": "2025-12-26",
  "lake_query": "Maschsee,Hannover,Germany",
  "resolution_in_m": 10,
  "max_cloud_coverage": 0.25,
  "copernicus_data_service": "ALL-BANDS-TRUE-COLOR",
  "harvester_width": 20.0,
  "residual_height": 0.2,
  "max_harvesting_depth": 1.8,
  "output_file": null
}

Response: 200 OK with application/geo+json file.

GET /get_capacitated_clustering

Runs capacitated clustering on the provided volume polygons and returns a clustered AOI as GeoJSON.

Query/body (JSON via GET with body or switch to POST if needed in your client):

{
  "max_volume": 100000.0,
  "eps": 50.0,
  "min_volume": 1000.0,
  "epsg": 3857,
  "volume_geojson": { "type": "FeatureCollection", "features": [/* ... */] },
  "boundary_geojson": null,
  "harvester_width": 20.0,
  "residual_height": 0.2,
  "max_harvesting_depth": 1.8,
  "bathymetry_service_url": "http://localhost:10005/geojson",
  "apa_service_url": "http://localhost:10003/api/get_apa",
  "apa_request_body": { /* see APA service docs */ }
}

Response: 200 OK with application/geo+json file download named clustered_aoi.geojson.

Notes

  • The service may contact external services for bathymetry and APA data. Ensure the URLs are reachable.
  • Caching: the /volume endpoint returns a pre-existing file if the expected file name is present in the working directory.
  • Error handling: External service errors return 502 Bad Gateway.
