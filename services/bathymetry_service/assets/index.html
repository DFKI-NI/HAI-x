Bathymetry API

Estimate lake bathymetry from sparse measurements and serve the results as GeoJSON.

Endpoints

  • GET /geojson — Generates (if needed) and returns the resulting GeoJSON file (maschsee_estimated_bathymetry_ex.geojson).

Overview

The pipeline loads a lake boundary from OpenStreetMap and bathymetry point measurements, interpolates depths on a grid using Ordinary Kriging (with a cubic fallback), clips to the lake polygon, and exports a FeatureCollection GeoJSON with per-point visual explanations.

Try it

Download the generated GeoJSON: GET /geojson

Static assets are served from /assets and data images from /data.
