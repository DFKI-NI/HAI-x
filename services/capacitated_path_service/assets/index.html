Cluster Connectors API

This service generates optimized connector paths for clustered geographical data (CVRP). Upload your clustered GeoJSON, specify start and end points, and choose a path generation mode:
  • Serpentine (Boustrophedon): Generates a back-and-forth pattern.
  • Unidirectional: Generates paths in a single direction.
  • Nearest Point: Connects points using a greedy nearest-neighbor heuristic.
